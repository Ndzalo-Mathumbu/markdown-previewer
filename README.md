# Markdown Previewer

A responsive Markdown Previewer built with React that allows users to write Markdown and see the rendered HTML output in real time. The project supports GitHub Flavored Markdown (GFM), including headings, lists, tables, code blocks, blockquotes, links, and images.

## Features

* Live Markdown preview
* GitHub Flavored Markdown support
* Responsive layout
* Real-time rendering using Marked.js
* Download Markdown files (.md)
* Export rendered content as PDF
* Custom modal for download options
* Styled tables, blockquotes, headings, and code blocks

## Technologies Used

* React
* Vite
* JavaScript (ES6+)
* SCSS
* Marked.js
* html2pdf.js
